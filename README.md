# 458p4-tile-set
There are a total of 5 different tile sets in this project; 
* Basemap set (background)
* Road markings with a basemap set (tile sets 1), 
* Thematic parking shapefile set (tile sets 2)
* Combination of both the thematic parking shapefile and the road markings on the basemap (tile sets 3)
* Thematic parking shapefile on basemap (tile sets 4)


### Basemap set
The base map set is monochrome, and zoomed in to showcase the Seattle area.
